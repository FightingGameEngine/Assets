
餓狼伝説 SPECIAL アクセルホーク

===============================================================================
スタートボタンを押しながらXボタンでREALBOUTモードになります
REALBOUTモードになるとイントロにREALBOUT餓狼伝説の文字が表示されます
(通常時は餓狼伝説 SPECIAL)
===============================================================================
◇基本技◇
 弱パンチ　= X
 弱キック　= A
 強パンチ　= Y
 強キック　= B

◇投げ技◇
エレキアタック         =  近距離６＋B 
ヘルボンバー           =  近距離４＋B

◇必殺技◇
スマッシュボンバー     =  １ため６＋XorY
トルネードアッパー     =  ２３６＋XorY
アクセルダンス         =  XorY連打
◇超必殺技◇
アクセルラッシュ       =  ４６３２１９＋Y
(ゲージ１使用)
===============================================================================
↓リアルバウトモード専用↓
===============================================================================
◇潜在能力◇
スクリューアッパー = ６４１２３６＋Y 
(体力が300以下ゲージ2使用)

◇コンビネーション◇
XorAor近Xor近A → X → A → Y
                       |＿６＋Y

Aor近A → Y → B

しゃがみX → X → ６＋Y


◇その他◇
避け攻撃                = X,A同時押し
挑発                    = enter
空中振り向き            = 空中でZ
フェイント技            = ４+ X,Y同時押し
