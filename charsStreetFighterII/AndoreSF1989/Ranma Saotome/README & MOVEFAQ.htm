1- INTRODUCCION

Espero que disfrutes esta nueva versión de Ranma basada en los sprites de SNES Ranma SuperBattle.

Es un personaje rápido con bastante pegada para que no tengas problemas a la hora de ganar a otros personajes, tipo Capcom o SNK, o que tengan una I.A muy elevada (mirar consejos de juego) 

Tiene algunos movimientos KOF, el Galactica Phantom,el Heaven´s Death, patada Robert, además de una gran cantidad de Super Motions y Special Motions nuevos.
