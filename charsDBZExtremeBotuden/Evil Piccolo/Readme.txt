This game will only run properly at game speed = "Fast 1"
Changing the speed will result in glitched audio and intros.
This is because characters were designed for a game speed of Fast 1.
*If trying to open in Vselect you may need to temporarily remove Saibamen
from the roster and then add then back in once finishing in Vselect.
